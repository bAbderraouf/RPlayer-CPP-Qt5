# RPlayer-CPP-Qt5

A multimedia player developed in **C++ using Qt 5**.
RPlayer is designed to **play audio** and **video** files, with additional **audio recording** functionality.

## Features
- 🎵 Audio playback
- 🎬 Video playback
- 🎙️ Audio recording
- ⏯️ Play, pause and stop
- 🔊 Volume control
- 🔇 Mute / unmute
- 🎚️ Seek through media using a timeline slider
- ⏱️ Display elapsed and remaining time
- 📂 Open media files

## Technologies
- C++
- Qt 5
- Qt Widgets
- QMediaPlayer
- QAudioRecorder
- qmake
- Project Status

## Media Support

RPlayer uses Qt 5 QMediaPlayer for audio and video playback.

Media format support depends on the multimedia backend and codecs available on the operating system.

On Windows, some media files may require additional codecs or multimedia components. If certain audio or video files cannot be played, installing the [K-Lite Codec Pack](https://www.codecguide.com/download_k-lite_codec_pack_basic.htm) may improve compatibility.
